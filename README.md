# Catálogo de barbería

Catálogo virtual (React + Vite) publicado con GitHub Pages en https://juancito33.github.io/catalogo/

- Las fotos están en `public/fotos/`.
- Los precios y los datos de la tienda los entrega un flujo de n8n (los precios se cambian desde un formulario privado).
- `npm run build` genera la carpeta `docs/`, que es la que publica GitHub Pages.
